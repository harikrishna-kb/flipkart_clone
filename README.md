# Flipkart Shopping System (Frontend Only)

A Flipkart-inspired e-commerce frontend built as a college Software Engineering project.

## Tech Stack
- React (Vite)
- React Router DOM
- HTML, CSS, JavaScript
- localStorage (for users and cart)

## Features
- Register & Login (frontend validation, localStorage)
- 20 dummy products with search, filter, and sort
- Product details page
- Shopping cart (add, remove, quantity, clear)
- Checkout with address & payment simulation
- Order success page with random Order ID
- Profile page with logout
- Responsive Flipkart-inspired design

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on Vercel
The project is ready for direct Vercel deployment. A `vercel.json` with SPA rewrites is included.
